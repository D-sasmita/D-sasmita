Computer Engineering student building **web, mobile, and data applications**. I learn by building, and I like projects that end up live.

- 📱 Published **MoodMelody** on Google Play
- 🤖 Built an AI-powered e-commerce platform and a RAG-based PDF Q&A app
- 📊 Shipped a live Olympics analytics dashboard
- 📄 Co-authored an IEEE paper on ML-based power grid load forecasting
